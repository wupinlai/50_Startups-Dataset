普通最小平方法（OLS）五大迴歸假設嚴謹檢驗

確保多元線性迴歸模型符合統計不偏性（Gauss-Markov 定理）

通過檢定 ✓

1. 線性關係（Linearity）

殘差對擬合值（Residuals vs. Fitted）呈現零均值水平隨機均勻分佈，無明顯二維拋物線或彎曲非線性特徵。

通過檢定 ✓

2. 殘差常態性（Normality）

Normal Q-Q Plot 顯示各點緊貼理論分佈對角線；Jarque-Bera 與 Omnibus 統計檢定量落在可接受之理論臨界範圍。

通過檢定 ✓

3. 殘差同質變異（Homoscedasticity）

隨著預測利潤提高，殘差變異數保持一致擴散度，未出現漏斗狀或錐型異質變異（Heteroscedasticity）現象。

通過檢定 ✓

4. 殘差獨立性（Independence）

Durbin-Watson 統計量為 1.751（接近理想值 2.0），表明樣本殘差間不存在嚴重之一階自相關問題。

通過檢定 ✓

5. 無嚴重共線性（Multicollinearity）

變異數膨脹因子（VIF）：R&D (2.62)、Marketing (2.70)、Admin (1.16)、State (1.47)，均遠低於警戒臨界值 5~10。
